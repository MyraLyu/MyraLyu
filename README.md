## Research Experience

### LabGym — AI-Powered Behavioral Analysis

Undergraduate Researcher | Ye Lab, Life Sciences Institute, University of Michigan

Contributing to an open-source deep learning platform for automated behavioral analysis, with an emphasis on model interpretability and temporal behavioral patterns.

My contributions include:

- Developing frame-level probability matrices to visualize behavioral classification confidence.
- Designing state transition maps to characterize directional transitions between behavioral states.
- Developing behavioral motif discovery tools to identify recurring behavioral sequences.
- Integrating analytical and visualization features into the LabGym software pipeline.

[View Repository](https://github.com/MyraLyu/LabGym)
